# TeatrFlow

Aplikacja do obsługi rezerwacji miejsc na spektakle teatralne dla grup zorganizowanych - zgłaszanie grup, i logiczne dopasowanie terminu z zaznaczonego zakresu data.

## Szybki start

```bash
git clone https://github.com/75gk2/TeatrFlow.git
cd TeatrFlow
docker compose up --build -d
```

Aplikacja: http://localhost:8080
